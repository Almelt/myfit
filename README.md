# MyFit — 自分専用の筋トレ記録アプリ

BurnFit のような筋トレ記録アプリを、PWA（インストールできるWebアプリ）として作ったものです。
ビルド不要の HTML / CSS / JavaScript のみで動きます。

## 機能
- **ワークアウト記録**: 種目追加 → セットごとに kg・回数を入力 → ✓で完了。前回の記録を表示・自動入力
- **休憩タイマー**: セット完了で自動スタート（±15秒・スキップ、終了時に振動と音）
- **ルーティン**: よく行うメニューを保存してワンタップで開始
- **カレンダー**: トレーニングした日を部位の色で表示。過去の日付の記録も追加・編集できる
- **統計**: 週ごとのボリューム、部位別セット数、種目ごとの推定1RM推移、自己ベスト
- **種目一覧**: 約60種目（胸・背中・肩・脚・腕・腹筋・有酸素）＋オリジナル種目の追加。ひらがな検索OK
- **自己ベスト更新の表示**、トレーニング中の画面スリープ防止、オフライン動作
- **バックアップ**: JSON ファイルへ書き出し／復元

### v0.2 で追加
- **今日のおすすめプログラム**: 部位ごとの回復状況（中1日以上）と過去の記録から自動作成。回復済みのルーティンがあれば優先。前回全セット10回以上できた種目は重量アップを提案
- **体重記録**: 体脂肪率も任意で記録、統計タブに推移グラフ
- **食事記録**: 朝・昼・間食・夕の食事を kcal / PFC で記録。よく食べる食品リスト（目安値）と「最近食べたもの」から素早く入力
- **目標カロリー・PFC**: 設定のプロフィール（性別・年齢・身長・活動レベル・目標）と最新体重から計算（Mifflin-St Jeor 式）
- **日次レポート**: トレーニング・体重・食事・アドバイスを1画面に。テキストで共有・コピー可

## 今後の予定（Android ネイティブ化が必要なもの）
- アプリを閉じていても休憩終了を通知（ローカル通知）
- Garmin のデータ取得（Garmin Connect → ヘルスコネクト → アプリで読み取り。歩数・睡眠・心拍・消費カロリーを日次レポートへ）

## PC で動かす
```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```
ブラウザで http://localhost:8080/ を開きます。

主要な操作がすべて動くかの自動テスト（Edge を画面なしで使用・約30秒）:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run-smoke.ps1
```スマホ表示の確認は、開発者ツール（F12）のデバイスモードが便利です。

## Android スマホに入れる
PWA のインストールには HTTPS での公開が必要です。無料の **GitHub Pages** が手軽です。

1. GitHub にリポジトリを作り、この `myfit` フォルダの中身を push
2. リポジトリの Settings → Pages で公開ブランチを選ぶ
3. Android の Chrome で公開URLを開き、メニュー →「アプリをインストール」（または「ホーム画面に追加」）

これでホーム画面のアイコンから全画面アプリとして起動できます。

> 記録はスマホのブラウザ内に保存されます。定期的に「設定 → バックアップを書き出す」をしてください。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | デザイン |
| `js/exercises.js` | 部位・器具・標準種目のデータ |
| `js/foods.js` | よく食べる食品の栄養データ（目安） |
| `js/store.js` | データの保存（localStorage） |
| `js/plan.js` | 今日のおすすめ・目標カロリー・アドバイスのルール |
| `js/app.js` | 画面描画と操作 |
| `manifest.webmanifest`, `sw.js`, `icons/` | PWA（インストール・オフライン）用 |

`js/` や `css/` を変更して公開するときは、`sw.js` の `CACHE` の値（`myfit-v1` → `myfit-v2` など）を上げると、スマホ側でも新しい版に確実に切り替わります。
